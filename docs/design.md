# claude-cert-drill 設計

Anthropic の Claude の資格の試験勉強用アプリ。iPhone のホーム画面アプリ（PWA）として GitHub Pages から配る。
最初に載せるのは **Claude Certified Architect – Foundations（CCAR-F、旧称 CCA-F）**。
同じ仕組みで CCAR-P・CCAO-F・CCDV-F などを足せるようにする。

## 命名規則

| もの | 形 | 例 | 決まり |
|---|---|---|---|
| アプリ | `claude-cert-drill` | — | 対象は Claude の資格。ホーム画面の表示名は `cert-drill` |
| 資格 | 公式の試験コードを小文字・ハイフン | `ccar-f`、`ccar-p` | 旧称（CCA-F）は表示名にだけ残す。**ID は変えない**（記録のキーになる） |
| 置き場所 | `src/exams/<資格ID>/` | `src/exams/ccar-f/` | 資格の内容はここにだけ置く。仕組み（engine・store・ui）は資格名を知らない |
| 分野 | `d<番号>` | `d1` | 公式の Domain 番号 |
| 細目 | 公式の番号 | `1.1` | 公式の Task Statement 番号 |
| シナリオ | `s<番号>` | `s1` | 公式のシナリオ番号。シナリオの無い資格は持たなくてよい |
| 問題 | `<シナリオ>-<2 桁の連番>` | `s1-03` | 資格の中で一意。シナリオの無い資格は `d1-03` |
| 記録のキー | `<資格ID>:<問題ID>` | `ccar-f:s1-03` | 資格をまたいで衝突しない |
| URL | `#/<資格ID>/<画面>` | `#/ccar-f/practice` | 資格を選ぶ画面は `#/` |
| 保存先 | `claude-cert-drill`（develop 版は `claude-cert-drill-dev`） | — | localStorage のキー |

## CCAR-F の試験の形（このアプリが合わせる相手）

出どころは Anthropic の試験ガイド（Version 0.1）。60 問・120 分だけは第三者の情報。

| 項目 | 内容 |
|---|---|
| 形式 | 4 択・正解 1 つ。誤答は「知識や経験が不完全な人が選びそうなもの」。未回答は誤答扱いで、当て推量の減点は無い |
| 採点 | スケールスコア 100〜1000、合格 720。換算式は非公開 |
| 分野 | D1 エージェント設計とオーケストレーション 27% ／ D2 ツール設計と MCP 18% ／ D3 Claude Code の設定とワークフロー 20% ／ D4 プロンプト設計と構造化出力 20% ／ D5 コンテキスト管理と信頼性 15% |
| 細目 | 分野の下に Task Statement が 30 個（1.1〜5.6） |
| シナリオ | 6 つのうち 4 つがランダムに出る。問題はシナリオ（本番に近い状況設定）の上で問われる |

資格ごとの違い（問題数・時間・シナリオの有無・合格の目安）は資格の定義（`Exam`）に持ち、画面はそれを読む。

## 決めたこと

| 項目 | 決定 | 理由 |
|---|---|---|
| 配り方 | PWA（GitHub Pages、`main` → `/claude-cert-drill/`、`develop` → `/claude-cert-drill/dev/`） | guitar-drill と同じ。主な使い方は iPhone のホーム画面、オフラインで動く |
| 言語・ビルド | TypeScript + Vite + Preact | guitar-drill と同じ。問題の型（選択肢ごとの解説、細目の紐付け）を型で守る |
| 言葉 | 画面と解説は日本語。**問題文・選択肢・シナリオは英語が正**で、日本語訳（`translations.ja`）を持ち、英語／訳はタップ（英語だけを出し、押すか答えたら訳を出す）／併記／日本語を設定と出題画面で切り替える。既定は英語。見た目（端末に合わせる／ライト／ダーク）も設定で選ぶ | 本番は英語。英語のまま判断できるようにしつつ、理解の確認には日本語で読めるようにする（2026-11-04 にユーザーの依頼で日本語版を追加）。併記だと訳を先に読んでしまうので「訳はタップ」を足した |
| 問題 | **すべて自作**。試験ガイドの本文・サンプル問題は載せない | ガイドには「Confidential Need to Know」の表記がある。出題範囲の確認にだけ使う |
| 覚える単位 | 問題 1 問ごとに間隔反復。習熟は**細目ごと**に集計し、分野は配点で重み付けする | 本番は 30 の細目から出る。「どの細目が穴か」が一番の情報 |
| 記録 | localStorage（キー 1 つ、版付き、値ごとに検証）＋ JSON の書き出し／読み込み | ホーム画面版は Safari と保存領域が別 |
| 開発 | Docker の `node:22-alpine`、dev ポート 8009 | dev VM の Node は 16 |
| ブランチ | feature → develop → main。作業の前に Issue、`Refs #N`／本番で `Closes #N` | guitar-drill と同じ運用 |

## guitar-drill から変えたところ（資格試験に合わせる）

guitar-drill は「答えが計算で決まる問題を大量に作る」アプリ。こちらは「手で書いた判断問題を少数、深く解く」アプリなので、
同じ形にはしない。

1. **問題は生成しない、書く**。問題は `src/exams/<資格ID>` のデータで、テスト（`exams.test.ts`）がすべての資格の形を検査する
   （選択肢 4 つ・正解 1 つ・選択肢ごとの解説・細目とシナリオの実在・ID の形と重複なし・全細目に問題がある）
2. **選択肢ごとに解説する**。正解の理由だけでなく「その誤答がなぜ選ばれがちで、どこが違うか」を書く。本番の誤答は
   「不完全な理解で選びたくなるもの」なので、誤答の解説がそのまま弱点の地図になる
3. **シナリオの文はいつでも読み返せる**。問題の上に畳んで出し、タップで広げる
4. **模擬試験**：本番と同じくシナリオをランダムに選び（CCAR-F は 4 つ）、その問題を出す。本番の問題数があれば、それをシナリオの数で
   割った数ずつ選ぶ（CCAR-F は 1 シナリオ 20 問から 15 問 × 4 ＝ 60 問）。1 問あたりの時間で制限時間を決め、
   見直し用の旗、最後にまとめて採点。分野別の正答率と、配点で重み付けした正答率を出す
5. **練習**：間隔反復（期限切れ→未出題→期限前）。未出題を選ぶときは「配点 ×（1 − 習熟度）」の大きい分野から優先する
6. **合格の目安**：換算式は非公開なので点数は作らない。配点で重み付けした正答率を出し、**75% を独自の目安線**にする
   （720/1000 をそのまま 72% と読むのは根拠が無い。安全側に置く）
7. **参考**：細目ごとの要点（日本語）と、出題範囲外の一覧

## 構成

```
src/
  exams/         資格の内容。データだけ
    types.ts       Exam・Domain・Task・Scenario・Question の型
    index.ts       載せている資格の一覧
    ccar-f/        CCAR-F（exam.ts、scenarios.ts、questions/s1.ts…、notes.ts）
  engine/        出題（間隔反復、練習と模擬試験の組み立て、採点、習熟度）。DOM に触らない
  store/         記録（スキーマ、移行、検証、書き出し／読み込み）
  ui/            画面と部品
```

### 問題の形

```ts
interface Question {
  id: string;              // "s1-03"。記録のキーなので変えない
  scenario?: string;       // "s1"。シナリオの無い資格では無し
  tasks: string[];         // ["1.1", "5.2"]。先頭が主たる細目（集計はこれで行う）
  stem: string;            // 英語
  options: [Option, Option, Option, Option];
  answer: 0 | 1 | 2 | 3;
  point: string;           // 日本語。この問題で覚えること 1 行
}
interface Option { text: string; why: string }   // text は英語、why は日本語
```

表示のときに選択肢の順番を混ぜる（位置で覚えないように）。

### 画面

1. **資格を選ぶ**（`#/`）：載せている資格の一覧。資格が 1 つでも出す（前回の資格は覚えておき、起動時はそこへ）
2. **ホーム**（`#/<資格>`）：合格の目安（重み付き正答率と目安線）、「今日の練習」、模擬試験、分野ごとの習熟
3. **練習**：シナリオ（畳める）→ 問題 → 回答 → 正誤と選択肢ごとの解説
4. **模擬試験**：残り時間、問題の一覧（未回答・旗）、提出 → 採点 → 1 問ずつ見直し。途中で閉じても続きから（時間は画面を開いている間だけ進む）
5. **分野**：分野 → 細目の一覧（習熟度）→ 要点と、その細目だけの練習。範囲外の一覧
6. **設定**：記録の書き出し／読み込み／消去、1 回の練習の問題数
